# 베이직 요금제 안내

> 실습용 가상 문서입니다. 금액과 할인율은 적지 않습니다. 금액은 요금 시뮬레이터, 이벤트의 정확한 조건은 이벤트 목록(DB)이 기준입니다.

## 이런 고객에게 맞습니다
서비스를 막 도입했거나 API 호출과 저장 공간을 적게 쓰는 작은 팀에 맞는 입문 요금제입니다. 기본 요금이 가장 낮아서, 사용량이 기본 제공량 안에 머무는 동안에는 가장 경제적입니다.

## 기본 제공량과 초과 요금 방식
매달 정해진 양의 API 호출과 저장 공간이 기본으로 포함됩니다. 이를 넘겨 쓰면 넘긴 만큼 초과 요금이 붙습니다. API 호출은 천 회 단위로 올림해서 계산하므로 한 번만 넘겨도 천 회분이 청구되고, 저장 공간은 기가바이트 단위로 올림합니다. 세 요금제 중 초과 단가가 가장 높아서, 초과가 반복되면 상위 요금제보다 비싸질 수 있습니다.

## 지원 범위
이메일 문의와 도움말 센터를 제공합니다. 답변은 영업일 기준으로 처리하며, 장애 대응 우선순위는 상위 요금제보다 낮습니다.

## 상위 요금제를 검토할 신호
초과 요금이 몇 달 연속 붙거나, 초과 요금이 기본 요금보다 커졌다면 프로 요금제와 비교해 볼 때입니다. 비교는 한 달이 아니라 최근 몇 달의 평균 사용량으로 해야 한 달 튄 값에 흔들리지 않습니다.
