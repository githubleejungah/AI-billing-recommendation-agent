# 프로 요금제 안내

> 실습용 가상 문서입니다. 금액과 할인율은 적지 않습니다. 금액은 요금 시뮬레이터, 이벤트의 정확한 조건은 이벤트 목록(DB)이 기준입니다.

## 이런 고객에게 맞습니다
서비스를 업무에 꾸준히 쓰는 중간 규모 팀에 맞는 요금제입니다. 베이직보다 기본 요금은 높지만 기본 제공량이 훨씬 넉넉하고 초과 단가는 낮습니다. API 호출이나 저장 공간을 꽤 많이 쓰는 고객에게 맞습니다.

## 기본 제공량과 초과 요금 방식
API 호출과 저장 공간이 베이직보다 크게 늘어난 양으로 포함됩니다. 넘겨 쓴 만큼 초과 요금이 붙는 방식과 올림 규칙(API는 천 회 단위, 저장 공간은 기가바이트 단위)은 베이직과 같고, 초과 단가는 베이직보다 낮습니다.

## 지원 범위
이메일과 채팅 기술 지원을 제공하며, 장애 문의는 베이직보다 먼저 처리합니다. 사용량 보고서를 매달 받아 볼 수 있어 비용 관리를 하기 쉽습니다.

## 다른 요금제를 검토할 신호
사용량이 기본 제공량에 한참 못 미치는 달이 계속되면 베이직이 더 경제적일 수 있습니다. 반대로 초과 요금이 꾸준히 크게 붙는다면 엔터프라이즈와 비교해 봅니다.
