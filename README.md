# 과금 추천 에이전트 (AI Billing Recommendation Agent)

[![시연 영상](https://img.youtube.com/vi/JW4FIV1JBnw/maxresdefault.jpg)](https://youtu.be/JW4FIV1JBnw)

▶ [시연 영상 보기 (YouTube)](https://youtu.be/JW4FIV1JBnw) — Azure에 배포한 화면으로 시연 시나리오 1~10을 보여줍니다. 순서와 설명은 [시연 안내서](docs/demo_guide.md)에 있습니다.

고객의 이용·청구 데이터를 매달 분석해 **더 맞는 요금제를 고객이 묻기 전에 먼저 알리고**, 고객이 상담 없이 직접 바꾸거나 AI 상담·담당자 연결을 할 수 있게 하는 B2B SaaS용 제품입니다. 바꾸기 전에는 사내 결재에 쓸 비용 절감 검토서를, 바꾼 뒤에는 변경 확인서를 내려받습니다.

> AI Native 클라우드 앱 개발 과정의 프로젝트이자 포트폴리오입니다. **데이터는 모두 가상**이며, 실제 고객 정보는 쓰지 않습니다. 구현과 Azure 시연 배포까지 마쳤습니다(2026-11-08). 기능별 상태는 아래 "주요 기능" 표에 있습니다.

## 핵심 원칙

- **금액은 AI가 계산하지 않습니다.** 모든 금액은 계산 프로그램(`src/simulator.py`)이 내고, 리포트·서류·화면은 그 값으로만 채웁니다. AI는 근거 문서를 찾아 설명 문장만 씁니다.
- **고객 정보는 회사 밖 AI로 보내지 않습니다.** 외부 AI에는 이름·ID·이용 수치 없이 범주 정보("기본 제공량의 2~5배 초과")만 보냅니다. 자세한 내용은 [보안 정책](design/security.md)에 있습니다.
- **AI는 요금제를 바꾸지 않습니다.** 결제 권한자가 확인 화면에서 직접 누를 때만 접수되고, 적용일 전까지 취소할 수 있습니다.
- **명세 먼저(SDD).** 명세 → 계획 → 사람 승인 → 구현 순서로 만들고, 요구사항마다 테스트를 연결합니다.

## 주요 기능

| 기능 | 내용 | 상태 |
|---|---|---|
| 요금제 비교 계산 | 요금제·이벤트 조합별 12개월 총액, 월별 일정, 부가세(공급가액·세액·합계), 추천 안정성 | 완료 |
| 성수기 반영 | 24개월 기록에서 2년 연속 사용량이 느는 달을 찾아 달별 예측에 반영 | 완료 |
| 비용처리 서류 | 비용 절감 검토서·변경 확인서를 PDF·DOCX·XLSX로, 그래프 3개를 PNG로. 모든 형식의 숫자가 같음 | 완료 |
| 셀프 요금제 변경 | 접수 직전 재계산, 결제 권한자만, 같은 접수 두 번 방지, 적용 전 취소 | 완료 |
| 근거 문서 검색 | 지식 문서(가상) 키워드 검색, 고객이 받을 수 없는 이벤트 표시 | 완료(하이브리드 검색은 예정) |
| 리포트 검증 | AI는 숫자 대신 자리표시자만 쓰고 값은 검증 뒤 코드가 채움, 검색한 근거만 인용 | 완료 |
| 외부 AI 전송 보안 | 고객 정보는 범주만 담은 상황 카드로, 질문 속 개인정보 가림, 보내기 직전 검사(이름·ID·허용 밖 숫자·연락처), 승인된 정책 파일 | 완료 |
| 리포트 작성 실행(AI 호출) | 6단계 실행, 근거 검색 최대 5회, 시간 제한·재시도, 검증 실패 시 1회 다시 쓰기, 실행 기록, Slack(같은 리포트는 한 번만) | 완료(실제 API 확인) |
| 월간 선제 알림 | 데이터 품질 점검 후 대상 선별, 성수기 사전 알림 | 완료 |
| AI 상담·담당자 연결 | 위험한 질문은 AI가 답하지 않고 담당자에게 연결(접수 DB + Slack) | 완료 |
| 화면 | 고객 화면, 담당자 화면(운영 지표, 근거 원문 모달, 실명 조회 감사 기록) | 완료 |
| Azure 시연 배포 | App Service, Key Vault(관리 ID), Entra ID 로그인, App Insights, 예산 알림. Bicep + azd로 올리고 촬영 뒤 삭제([배포 안내](docs/deploy_guide.md)) | 완료(2026-11-08 올림·내림) |

## 구조

```
월간 선별(코드) ─ 고객마다: 수집 → 계산 → 근거 검색 → 설명 작성(AI) → 검증 → 알림
고객 화면 ─ 추천 상세·그래프·서류 내려받기 / 셀프 변경(AI 없음) / AI 상담 → 모르면 담당자 연결
```

지휘는 코드가 하고 AI는 판단이 필요한 곳(근거 찾기, 설명 쓰기)에만 씁니다. 자세한 구조와 이유는 [계획](design/plan.md)에 있습니다.

## 기술 스택

Python 3.13 · SQLite(가상 데이터) · Claude API · MCP(자체 읽기 전용 도구 서버) · reportlab·python-docx·openpyxl·matplotlib(서류·그래프) · Streamlit(화면) · GitHub Actions(CI) · Azure(시연 때만 배포, Bicep + azd)

## 실행

```bash
python -m venv .venv
.venv\Scripts\activate            # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt -r requirements-dev.txt
python database/init_db.py        # 가상 DB 생성(고객 203명, 시드 고정)
python -m pytest -q               # 전체 테스트
python src/simulator.py user_002  # 고객 1명 계산 결과
python src/agent.py user_002      # 리포트 작성(.env에 ANTHROPIC_API_KEY 필요, 결과는 output/)
python src/agent.py --purge       # 보관 기간이 지난 리포트·기록 지우기
python src/batch.py               # 월간 선별: 데이터 품질 점검 → 알림 미리보기·사내 요약(output/selection/)
python src/batch.py --announce-loyalty  # 장기 이용 혜택 시작 공지 미리보기(한 번만)
streamlit run src/app_customer.py                       # 고객 화면(127.0.0.1:8501)
streamlit run src/app_staff.py --server.port 8502       # 담당자 화면
```

## 실제 회사에 도입할 때: 지식 문서와 평가 질문

지금의 지식 문서와 평가 질문은 모두 가상이며, 개발 과정에서 직접 썼습니다. 실제 고객사에 도입할 때는 아래를 고객사의 자료로 바꿔야 정확도를 믿을 수 있습니다.

| 바꿀 것 | 누가 준비하나 | 이유 |
|---|---|---|
| 지식 문서(요금제 설명, 이벤트 안내, 변경 정책, 응대 가이드) | 고객사의 상품·영업 담당 부서 | 리포트와 상담 답변의 근거가 되는 사내 기준입니다. 금액·할인율은 문서에 쓰지 않고 청구 시스템 값만 씁니다. |
| 검색 평가 질문(조정용 20개 이상, 확인용 10개 이상) | 고객사 영업·상담 담당자 | 문서를 쓴 사람이 질문까지 쓰면 문서 표현을 따라가 점수가 실제보다 높게 나옵니다. 담당자가 평소에 쓰는 말로, **문서를 보기 전에** 씁니다. |
| 업무 용어 사전(같은 뜻의 다른 말, 예: 내역·기록, 플랜·요금제) | 고객사 업무 담당자 | 검색은 글자가 겹쳐야 찾습니다. 담당자들이 실제로 쓰는 말을 모아야 놓치는 질문이 줄어듭니다. |
| 고객 질문 평가 세트(EVAL-06) | 상담 연결로 쌓인 실제 질문 | 운영하면서 담당자에게 넘어온 질문을 개인정보를 가린 채 더합니다. |

현재 가상 자료 기준 검색 정확도(정답이 상위 3개 안): 조정용 질문 16/20(80%), 확인용 질문 7/14(50%). 확인용 질문은 조정에 쓰지 않은 새 표현이라 실제 사용에 더 가까운 값이며, 개선은 T7에서 합니다([design/tasks.md](design/tasks.md)).

## 화면 설계와 실제 개발

화면 목업(2026-11-08 승인)은 이 제품이 고려한 기능을 모두 담은 설계 기준입니다. 실제 개발에서는 고객사와 사용자 역할에 맞춰 필요한 기능만 골라(취사선택) 화면을 단순하게 만듭니다. 다만 가칭 코드, 실명 조회 기록, AI 상담 고지, 담당자 연결 버튼, 공급가액·세액 구분 같은 보안·검증 장치는 빼지 않습니다.
